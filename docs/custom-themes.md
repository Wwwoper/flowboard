# Пользовательские темы Flowboard

Flowboard поддерживает импорт и экспорт цветовых тем в формате JSON. Темы применяются только в текущем браузере и сохраняются в `localStorage`; они не меняют задачи, вложения или базу данных.

Библиотека и выбранная тема хранятся в `localStorage` текущего браузера. При повторном открытии Flowboard восстанавливается последний выбор. Данные библиотеки не входят в ZIP-резервную копию задач и не синхронизируются между браузерами или устройствами. Старая одиночная тема автоматически переносится в библиотеку при первом запуске новой версии.

## Как загрузить или сохранить тему

1. Откройте **Настройки** в верхней панели.
2. Нажмите **Импорт темы JSON** и выберите `.json`-файл.
3. Тема применяется сразу. Она остаётся активной после перезагрузки и переключения между светлым и тёмным режимами.
4. После импорта тема сохраняется в библиотеке браузера. Выберите её в списке **Сохранённые темы**, чтобы переключиться без повторной загрузки JSON.
5. Нажмите **Экспорт темы JSON**, чтобы сохранить активную палитру в файл и передать её другому пользователю.
6. Выберите **Стандартная палитра Flowboard**, чтобы вернуться к встроенному оформлению, не удаляя сохранённые темы.
7. Нажмите **Удалить выбранную тему**, чтобы удалить только её из библиотеки. Остальные темы сохранятся.

Пример темы: [`themes/moonshade-flowboard.json`](themes/moonshade-flowboard.json). Его можно импортировать прямо в приложение.

## Формат файла

```json
{
  "name": "Moonshade",
  "version": 1,
  "colors": {
    "light": {
      "accent": "#7654ba",
      "gh-primary": "#7654ba"
    },
    "dark": {
      "accent": "#b9a0f5",
      "gh-primary": "#8061c2"
    }
  }
}
```

- `name` — название темы, от 1 до 60 символов. Повторный импорт темы с тем же названием обновляет сохранённую запись вместо создания дубликата.
- `version` — версия формата. Сейчас поддерживается только `1`.
- `colors.light` и `colors.dark` — наборы цветов для светлого и тёмного режимов.
- Можно указывать только те цвета, которые хотите изменить. Остальные останутся из встроенной палитры.
- Значения цветов должны быть в формате `#RGB` или `#RRGGBB`.
- Размер JSON-файла не должен превышать 256 КБ.

Неизвестные ключи цветов отклоняются. Импорт принимает только цвета, а не CSS, HTML или JavaScript.

## Доступные ключи цветов

| Ключ | Назначение |
| --- | --- |
| `page` | Фон страницы |
| `surface` | Карточки, панели и окна |
| `surface-soft` | Вторичный фон |
| `ink` | Основной текст |
| `ink-soft` | Вторичный текст |
| `muted` | Подписи и подсказки |
| `line` | Обычные границы |
| `line-strong` | Контрастные границы |
| `accent` | Акцент и фокус |
| `accent-dark` | Более контрастный акцент |
| `accent-pale` | Светлая/приглушённая заливка акцента |
| `green`, `orange`, `red` | Семантические цвета |
| `gh-column` | Фон колонки доски |
| `gh-control` | Фон полей и тихих кнопок |
| `gh-control-hover` | Фон элемента при наведении |
| `gh-blue-bg`, `gh-blue-fg` | Синяя метка: фон и текст |
| `gh-green-bg`, `gh-green-fg` | Зелёная метка: фон и текст |
| `gh-yellow-bg`, `gh-yellow-fg` | Жёлтая метка: фон и текст |
| `gh-red-bg`, `gh-red-fg` | Красная метка: фон и текст |
| `gh-purple-bg`, `gh-purple-fg` | Фиолетовая метка: фон и текст |
| `gh-primary`, `gh-primary-hover`, `gh-primary-ink` | Основная кнопка: фон, фон при наведении, текст |
| `gh-brand-start`, `gh-brand-end` | Начальный и конечный цвета градиента логотипа |
| `gh-marker-todo`, `gh-marker-doing`, `gh-marker-waiting`, `gh-marker-done` | Цвета маркеров четырёх колонок |

Встроенные темы и импортированные темы используют один и тот же набор параметров. При экспорте встроенной темы Flowboard создаётся JSON с текущей встроенной палитрой для обоих режимов; можно отредактировать его и снова импортировать.
