# История рабочих наборов

## Назначение

История рабочих наборов должна позволять восстановить жизненный цикл набора и состав его задач на момент последнего завершения, не полагаясь на текущие связи `workset_memberships`.

## Источник истории

`workset_events` — append-only журнал. Каждое событие хранит снимок названия набора и, если событие относится к задаче, её ID, название, статус и дату закрытия. `workset_id` и `task_id` в журнале не являются внешними ключами: удаление исходной записи не должно менять исторические идентификаторы.

Период членства начинается с `task_added` и заканчивается `task_removed` либо `task_deleted`. Повторное добавление той же задачи образует новый период. События статуса задачи обновляют снимок её состояния внутри текущего периода. Событие `completed` сохраняет размер набора на момент завершения.

## Жизненный цикл

- `created` — набор создан.
- `renamed` — набор переименован.
- `task_added` — задача добавлена в набор.
- `task_removed` — задача убрана из набора, но остаётся в проекте.
- `task_deleted` — задача удалена из проекта; событие не означает обычное удаление членства.
- `task_status_changed` — статус задачи изменён.
- `task_completed` — задача переведена в `done`.
- `task_reopened` — задача переведена из `done` в незавершённый статус.
- `completed` — все задачи набора завершены; событие содержит снимок количества задач.
- `reactivated` — после повторного открытия задачи набор снова стал активным; состав при этом не меняется.
- `deleted_empty` — набор удалён после удаления последней задачи из него.

Состав завершённого набора нельзя менять операциями удаления членства или переноса. Удаление самой задачи из проекта остаётся отдельной операцией и фиксируется как `task_deleted`.

## Представление

Окно истории показывает отдельные группы активных и завершённых наборов. Для каждого набора отображаются дата создания, последнее завершение (если было), длительность последнего завершённого цикла (от создания или последней реактивации), количество задач при завершении и суммарные за всю историю количества добавлений, удалений из набора и удалений из проекта.

Раскрываемый состав показывает задачи, входившие в набор на момент последнего завершения (для активного набора — текущий состав), и отдельные списки задач, убранных из набора и удалённых из проекта до этого момента. Счётчики этих двух причин удаления не смешиваются. Для каждой задачи отображаются статус и дата завершения, если известны. Существующая задача открывается в панели задачи; удалённая показывается без ссылки.

Хронология сгруппирована по набору и типизирована. Первые 100 событий загружаются сразу; последующие страницы запрашиваются по offset. Порядок: `created_at DESC, id DESC`.

## Совместимость

Миграция SQLite сохраняет все существующие строки `workset_events`, добавляет снимки статуса и счётчиков и снимает внешние ключи с `workset_id`/`task_id`. Старые события, для которых старый внешний ключ уже обнулил ID, остаются без ID; восстановить его из существующих данных невозможно. Старые события удалённых наборов без ID группируются по проекту и снимку названия; если в старых данных несколько удалённых наборов одного проекта имели одинаковое название, точно разделить их уже невозможно.

ZIP-экспорт сохраняет новые поля и стабильные исторические ID. Восстановление принимает как новые архивы, так и старые архивы без новых полей; ID задачи/набора в событии не обязан ссылаться на существующую запись.

## Критерии готовности

- События добавления, удаления из набора и удаления из проекта имеют разные типы и сохраняют ID/снимок задачи.
- Повторное добавление создаёт новый период членства, предыдущий период не теряется.
- Завершённый набор не допускает удаления/переноса задачи через API.
- Повторное открытие задачи фиксируется и реактивирует набор без события изменения состава.
- История отображает состав, ранее убранные задачи, статусы, даты и переходы к существующим задачам.
- Пагинация, пустые состояния, ошибки загрузки и клавиатурная доступность обработаны.
- Миграция и ZIP restore сохраняют старые данные и новые исторические поля.
